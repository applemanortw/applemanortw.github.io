# 設計方向：蘋果莊園 Apple Manor

示意圖：`docs/design/desktop-home.png`、`mobile-home.png`、`desktop-product.png`、`mobile-product.png`
可在瀏覽器開啟的示意稿：`docs/design/mockup.html`

## 1. 風格定位

現代簡約、安靜、有草本與漢方的溫度。大量留白，讓商品圖成為主角。
原站的黑色選單、藍色高亮、米灰底全部拿掉，只保留品牌 Logo 的蘋果樹意象與「堅持草本 崇尚自然」的精神。

## 2. 色票

| 用途 | 色碼 | 說明 |
| --- | --- | --- |
| 頁面底色 | `#F7F4EE` | 暖米白，呼應手工皂與宣紙的質感 |
| 卡片／頁首底色 | `#FFFFFF` | 純白，和底色形成輕微層次 |
| 主要文字 | `#2B2A26` | 近黑的暖灰，對比度 13:1 |
| 次要文字 | `#6F6B63` | 說明文字，對比度 5.2:1（符合 AA） |
| 分隔線 | `#E6E1D7` | 細線與邊框 |
| **品牌主色** | `#3F6B4A` | 草本深綠，用於按鈕、連結、作用中導覽。白字對比度 6.3:1 |
| 主色深階 | `#2E5237` | hover 與標籤文字 |
| 主色淡階 | `#E8EFE6` | 分類標籤底色 |

只有一個品牌色。綠色來自「堅持草本」的品牌精神，也和原站的綠色連結色系一脈相承。

備選方案：若想更貼近「蘋果」意象，主色可換成蘋果紅 `#B5443A`。我建議綠色，因為商品多為米、粉、紫等柔和色，綠色當背景襯托時更不搶戲。

## 3. 字體（2 種）

| 用途 | 字體 | 字重 |
| --- | --- | --- |
| 標題、品牌名 | Noto Serif TC | 600 |
| 內文、導覽、按鈕 | Noto Sans TC | 400 / 500 / 700 |

明體標題帶出漢方的沉穩感，黑體內文維持易讀。兩種字體都從 Google Fonts 載入，只載入用到的字重。

## 4. 版面

- 容器最大寬 1120px，左右 24px 留白；手機 16px。
- 商品圖統一 **1:1 正方形**，圓角 12px，背景與 AI 生圖的米白棚拍背景一致。
- 商品卡片：桌機 3 欄、平板 2 欄、手機 2 欄。
- 按鈕：膠囊形，實心綠（主要動作）與綠框線（次要動作）。

## 5. 頁面結構

```
/                      首頁：品牌標語 + 理念 + 4 個分類入口 + 精選商品 + 聯絡我們
/soap/                 手工皂商品（14）
/plant/                植物調理（3）
/bath/                 居家樂活（2）
/gift/                 精緻禮盒（4）
/products/<slug>/      23 個獨立商品頁（取代原站的彈出視窗）
```

- 導覽列：Logo 在左、5 個連結在右；手機收成漢堡選單。
- 每頁頁尾：聯絡我們（電話按鈕、LINE 按鈕、LINE QR code）+ 版權。
- 商品頁：左圖右文，規格用「標籤／內容」兩欄表呈現，底部放 LINE 與電話按鈕。
- 「關於蘋果莊園」併入首頁，不另開頁面，因為原站首頁內容就是品牌介紹。

## 6. 聯絡方式

維持原站做法：電話 + LINE 官方帳號 QR code，但全部改成可以直接點的連結。
- 電話：`tel:+886227115939`
- LINE：`https://lin.ee/jkzuyIV`（同時顯示 QR code，給桌機用戶掃描）

## 7. 無障礙與效能

- 所有文字與底色對比度至少 4.5:1。
- 鍵盤可操作：導覽、卡片、按鈕都有可見 focus 樣式。
- 商品圖 WebP，提供 `alt` 文字；首圖以外一律 lazy load。
- 不使用任何 JS 框架在瀏覽器端執行；只有漢堡選單需要幾行 JS。
